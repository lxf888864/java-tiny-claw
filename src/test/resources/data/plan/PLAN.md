# PLAN：命令行计算器

## 任务理解
实现一个 Java 命令行计算器 Calculator.java，支持 + - * / 与括号，除数为 0 时给出友好提示。

## 架构设计
- Tokenizer：把表达式字符串切分为数字、运算符、括号
- Parser：递归下降解析（expr → term → factor），天然处理优先级与括号
- Main：读取命令行参数，输出结果或错误信息

## 技术选型
- 纯 JDK，无第三方依赖，javac 直接编译
- 数值使用 double，输出时去掉多余的 .0

## 风险
- 非法输入（如 "1 +"、"(2"）需要给出明确错误，而不是抛出堆栈
